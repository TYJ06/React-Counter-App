React Counter with LocalStorage

A beginner React counter application that allows users to increase, decrease, and reset a counter. The application also uses browser localStorage to save and retrieve the counter value.

Features
Increase and decrease the counter by 1
Increase and decrease the counter by 5
Reset the counter
Save the current counter value
Retrieve and display the saved value using localStorage

Technologies
React
JavaScript
CSS
HTML
Browser localStorage
Learning Objectives

This project was created to practice React fundamentals, including useState, event handling, JavaScript functions, JSX, and using localStorage to store and retrieve data.
